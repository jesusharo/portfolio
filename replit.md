# portfolio draft

A portfolio web app exported from Figma Make. Built with React 18, Vite 6, Tailwind CSS 4, and shadcn/Radix UI components.

## Running the project

```
npm run dev
```

The dev server starts on **port 5000**. The "Start application" workflow handles this automatically in Replit.

## Stack

- **React 18** + **React Router 7**
- **Vite 6** (bundler / dev server)
- **Tailwind CSS 4** + **shadcn/Radix UI** components
- **MUI 7** (Material UI icons / components)
- **Framer Motion** (`motion`)
- No backend — purely frontend / static

## Project structure

```
src/
  main.tsx          # Entry point
  app/
    App.tsx         # Root component
    routes.ts       # React Router routes
    types.ts        # Shared types
    components/     # UI components
    data/           # Static data
    hooks/          # Custom hooks
  imports/          # Figma-exported assets & components
  styles/           # CSS files (Tailwind, fonts, theme)
index.html
vite.config.ts
```
